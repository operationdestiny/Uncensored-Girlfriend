# Image-to-Companion Matching Audit

This launch package uses category-aware matching. Before public launch, do a visual audit so every image feels intentionally paired with the companion profile.

## Matching rules

Modern images:
- Smiling / café / casual: Coffee Shop Regular, Comfort, Slice of Life, Romance
- Hoodie / classroom / campus: College Classmate, Campus, Sarcastic
- Professional / office: Rival Coworker, Rival, Mean, Romance
- Soft home setting: Quiet Roommate, Comfort, Slice of Life
- Rainy / cinematic / moody: Rainy Night Stranger, Mystery, Romance

Fantasy / anime images:
- Dark elegant: Vampire Duchess, Gothic, Mystery
- Armor / weapons: Royal Bodyguard, Adventure, Protective
- Tavern / medieval: Tavern Keeper, Fantasy, Comfort
- Magic / forest: Forest Healer, Fantasy, Comfort
- Moon / occult: Moonlit Oracle, Fantasy, Mystery

Guys:
- Modern casual: Protective Neighbor, Comfort, Slice of Life
- Office / sharp: Rival Coworker, Rival, Sarcastic
- Fantasy armor: Royal Guard, Fantasy, Protective
- Investigative / moody: Mystery Journalist, Mystery, Adventure

## Launch checklist

- No duplicate names.
- Official companions show no public view count.
- Public Creations show creator, views, share, save, and report.
- Official companions show save/report but no creator or views.
- Cards go directly to chat.
- `/character/[slug]` redirects to `/chat/[slug]`.
- Chat portrait opens clean image modal.
- User-facing wording says companion, not character.
